# Home

This vault contains four kinds of work context and one central task list.

## Tasks

All tasks live in [[Tasks]]. Do not duplicate them inside Project or Note files.

## Organisations

Companies, clients, suppliers, partners, departments and institutions.

Create with [[Templates/Organisation]]. Store in `Organisations/`.

## People

People you work with and the context needed to work with them well.

Create with [[Templates/People]]. Store in `People/`.

## Projects

Outcomes that have a finish line.

Create with [[Templates/Project]]. Store in `Projects/`.

## Notes

Meetings, research, decisions, ideas, processes and general context.

Create with [[Templates/Note]]. Store in `Notes/`.
