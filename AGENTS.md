# Vault map

This is a small, beginner-friendly Obsidian Work OS. Keep it simple. `CLAUDE.md` and `AGENTS.md` must remain identical.

## Where to go

- Start with `Notes/Getting Started with This Vault.md` if you need the overall model.
- Use `Tasks.md` for every task.
- Store work context in `Organisations/`, `People/`, `Projects/` and `Notes/`.
- Use `Templates/Organisation.md`, `Templates/People.md`, `Templates/Project.md` or `Templates/Note.md` before creating the matching record.
- Read `System/connections.md` before using an external service.
- Read `Notes/Recommended Connections.md` before setting up a connection.
- Read `Notes/Principles of an Agent-Friendly Obsidian Vault.md` before changing the structure.

## Keep these rules

- Each task appears once in `Tasks.md`; do not copy tasks into Projects or Notes.
- A Project has a finish line. A meeting is a Note.
- Preserve existing content, frontmatter, useful links and uncertainty.
- Do not add record types, folders or automation unless the user asks.
- Never store secrets. Confirm before external sends, deletions or permission changes.
